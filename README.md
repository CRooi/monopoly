# 大富翁（H5 联机版）

玩家各自在手机或电脑上打开网页，用房间码进同一个房间，按经典大富翁规则对局，地名是 22 个常见国家。

- 前端：React + Vite + Tailwind + shadcn（根目录）
- 后端：Express + ws + SQLite（`api/`，运行于 Bun）
- 共享类型与棋盘数据：`shared/types.ts`

## 开发

```bash
bun install && bun install --cwd api
bun run dev:api   # 后端 http://localhost:3001（watch 模式）
bun run dev       # 前端 http://localhost:5173，/api 与 /ws 代理到后端
```

同一局域网的手机访问 `http://<电脑IP>:5173` 即可加入。

## 房间

- 首页填昵称、选头像后创建房间，或输入 4 位房间码加入；房主可以复制邀请链接（`/?room=房间码`）
- 开局前房主可以修改初始资金、轮数上限、免费停车奖池、是否允许观战，可以请出玩家
- 游戏进行中不能再加入玩家，可以观战；玩家掉线卡住回合时，房主可以把他请出（按破产处理）
- 刷新或断网后自动回到房间，身份保存在浏览器里

## 大屏

打开 `/?overview=房间码`（或 `/?overview` 后输入房间码），适合投到电视或投影上，只读展示棋盘、玩家和记录。

## 房间空闲解散

- 房间内 30 分钟没有任何操作会自动解散（可用 `ROOM_IDLE_MINUTES` 调整），进行中的对局记为「已终止」，可在后台对局记录回看
- 解散前 5 分钟所有人会看到倒计时提醒，任何人点击「延长对局」即重新开始计时

## 重启与部署

- 每次操作后房间都会写入 `api/monopoly.sqlite`，后端重启或重新部署后房间原样恢复
- 后端收到 SIGTERM 或 SIGINT 时先通知所有在线玩家，页面显示全屏的「系统更新中」
- 后端每次启动有不同的启动编号，页面重连后发现编号变了会自动刷新一次换上新版前端，并回到原房间

## 管理后台

1. 复制 `api/.env.example` 为 `api/.env`，设置 `ADMIN_PASSWORD`（未设置时后台不可用）
2. 打开 `/?admin`，输入密码进入后台：
   - 房间：查看所有房间、在线人数和空闲倒计时，可以实时观看对局
   - 对局记录：每局的每次操作都会记录到 SQLite，可按真实时间回放，拖动或点击任意事件查看当时的局面
   - 下载回放：导出 `.mfreplay` 文件，在 `/?replay` 本地回放查看器里离线播放

## 调试台（多玩家测试）

打开 `http://localhost:5173/?debug`（开发环境首页底部也有入口）：

- 一键开局：槽位 0 建房当房主，其余玩家自动加入
- 加入已有房间：按房间码逐个加人或加观战者
- 每个槽位对应一个 `?slot=N` 的标签页，身份存储互相独立
- 生产构建设置 `VITE_DEBUG=1` 可在首页显示入口

## 测试

```bash
bun run test      # 游戏引擎单元测试
```

## 部署

```bash
bun run build     # 产出 dist/（公开静态文件）和 dist-admin/（后台代码，登录后才下发，部署时一起带上）
bun run start     # 后端同时托管 dist/，默认端口 3001（PORT 环境变量可改）
```

## 规则

- 2～8 人，开局随机排序，每人领初始资金；经过起点领 $200
- 停在无主的地上可以购买，停在别人的地上付租金，抵押中的地不收租
- 集齐同色国家后空地租金翻倍，并可以盖房，同色要平均盖，4 栋房子后升级为酒店；卖房按半价
- 航线按拥有条数收租（$25/$50/$100/$200）；公用事业按骰子点数的 4 倍，两家都有为 10 倍
- 掷出双数再掷一次，连续三次双数直接入狱；入狱后可以交 $50 保释、用出狱卡，或掷出双数出狱，第三次还没掷出就交保释金出狱
- 现金不够付款时可以卖房、抵押、和别人交易凑钱，凑不够就破产，资产交给债主（欠银行时地产收归银行）
- 任何时候都可以向其他玩家提出交易，用地产、现金、出狱卡交换；同色还有房子的地不能交易
- 只剩一人时获胜；设置了轮数上限时，到达上限按总资产（现金、地价、房子）排名；房主也可以随时结束对局
